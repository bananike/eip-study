2. 순차 스캔·스택 사용:
   - A → out: `A`
   - `+` → stack: `+`
   - B → out: `A B`
   - `*` → stack: `+ *` (`*` > `+`)
   - C → out: `A B C`

   - D → out: `A B C * + D`
   - 종료 pop: `A B C * + D -`

정답 ③ `A B C * + D -`.
