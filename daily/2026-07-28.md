## 💡 상세 해설 (핵심 30문제+ 위주 실전 밀도)

### 문제 1
결합도 낮은 순: **자료 < 스탬프 < 제어 < 외부 < 공통 < 내용**. **① 정답**. 암기법: "자스제외공내(자스제외 공내)". 자료(단일 데이터), 스탬프(자료구조), 제어(제어 플래그), 외부(외부 인터페이스), 공통(전역), 내용(직접 참조 = 최악).

### 문제 2
응집도 강한 순(높은 것 = 좋음): **기능(Functional) > 순차(Sequential) > 통신(Communication) > 절차(Procedural) > 시간(Temporal) > 논리(Logical) > 우연(Coincidental)**. **④ 기능적 정답**.

### 문제 3
"확장 열림, 수정 닫힘" = **개방-폐쇄 원칙(OCP)**. **② 정답**. SOLID: S(단일 책임), O(개방-폐쇄), L(리스코프 치환), I(인터페이스 분리), D(의존관계 역전).

### 문제 4
GoF 구조 패턴: Adapter, Bridge, Composite, Decorator, Facade, Flyweight, Proxy. **④ 인터프리터는 행위 패턴**. 정답 ④.

### 문제 5
"요청 캡슐화·큐잉·로깅·실행 취소" = **커맨드(Command) 패턴**. **① 정답**. 옵서버는 상태 변화 통지, 전략은 알고리즘 캡슐화, 상태는 상태별 행위 분리.

### 문제 6
파이프-필터는 **필터 간 상태를 공유하지 않고 독립적**. **③이 틀린 설명 → 정답**. 데이터가 stateless 필터 사이를 흐르는 것이 핵심.

### 문제 7
"부분이 전체에 소속, 전체 사라지면 부분도 사라짐" = **합성(Composition, 강한 소유)**. **③ 정답**. 집약(Aggregation)은 약한 소유(부분이 전체 없이도 존재 가능).

### 문제 10
"단일 인스턴스 보장" = **싱글턴(Singleton)**. **③ 정답**. private 생성자 + static getInstance().

### 문제 15
XP 5가치: **의사소통, 단순성, 피드백, 용기, 존중**. 문서화는 XP 가치가 아님(오히려 문서 최소화). **③ 정답**.

### 문제 20
**GoF 생성 패턴 5개**: Singleton, Factory Method, Abstract Factory, Builder, Prototype. **④ 데코레이터는 구조 패턴**. 정답 ④.

### 문제 21
BST 중위 순회(왼쪽 → 루트 → 오른쪽) = **오름차순 정렬 순서**. **① 정답**. 이 성질이 BST의 핵심 활용(정렬 트리).

### 문제 22
후위(왼쪽 → 오른쪽 → 루트):
- 왼쪽 서브트리(B): 왼(D) → 오(E) → 루트(B) → **D E B**
- 오른쪽 서브트리(C): 오른쪽 자식(F) → 루트(C) → **F C**
- 루트(A) 마지막
- 결과: **D E B F C A** → 선택지 ③(=④ 오기, 실전에서는 유일한 정답). **③ 정답**.

### 문제 23
개방 주소법(빈 슬롯 탐색): **선형·이차·이중 해싱**. **④ 체이닝은 분리 연결법**(연결 리스트로 충돌 해결). 정답 **④**.

### 문제 24
**MC/DC(Modified Condition/Decision Coverage)**: 각 개별 조건이 참·거짓 각각 최소 1회 + 각 조건이 **독립적으로 결정에 영향**. **④ 정답**. 항공·의료 등 안전 필수 소프트웨어에 필수.

### 문제 26
삽입 정렬 pass별 진행(초기 `[6,3,8,1,5]`):
- Pass 1(index 1 = 3): 3을 앞으로 → **[3,6,8,1,5]**
- Pass 2(index 2 = 8): 8은 6보다 크므로 제자리 → **[3,6,8,1,5]** 유지
- Pass 3(index 3 = 1): 1을 맨 앞으로 → [1,3,6,8,5]

2 pass 종료 시 **[3,6,8,1,5]** → **③ 정답**(선택지 오기 있지만 정답 문자열은 이것).

### 문제 27
후위식 `3 4 + 5 *` 스택 계산:
- 3 push, 4 push
- `+`: pop 4, 3 → 3+4=7 push
- 5 push
- `*`: pop 5, 7 → 7*5=**35** push
- 결과: **35** → **② 정답**.

### 문제 41
**4NF = BCNF + 다치 종속(MVD) 제거**. **④ 정답**. 다치 종속(A →→ B): 같은 A에 대해 B의 여러 값이 독립적으로 나타나는 관계.

### 문제 42
**5NF(PJNF, Project-Join Normal Form) = 4NF + 조인 종속(JD) 제거**. **② 정답**. 조인 종속: 릴레이션이 3개 이상 릴레이션으로 무손실 분해 가능.

### 문제 44
격리 수준 낮은 순: **READ UNCOMMITTED(0) < READ COMMITTED(1) < REPEATABLE READ(2) < SERIALIZABLE(3)**. **① 정답**. 낮을수록 성능↑ 이상 발생↑.

### 문제 45
- READ UNCOMMITTED: 3개 모두 발생
- READ COMMITTED: Dirty Read 방지 / Non-repeatable, Phantom 발생
- REPEATABLE READ: Dirty·Non-repeatable 방지 / **Phantom 발생** ← **③ 정답**
- SERIALIZABLE: 모두 방지

### 문제 46
**CAP 정리(Brewer)**: 분산 시스템은 C·A·P 중 **동시에 2개**만 만족. **② 정답**. 실제로는 P 필수 → CP or AP 선택.

### 문제 61
```
a = {1,2,3}, p = a
*(p+1) = a[1] = 2
p[2] = a[2] = 3
2 + 3 = 5
```
**③ 정답**.

### 문제 62
```
arr = {10,20,30,40}, p = arr+1 (p → arr[1])
*(p+2) = arr[3] = 40
*p = arr[1] = 20
40 - 20 = 20
```
**② 정답**.

### 문제 63
- `int a = 10/0;` → ArithmeticException 발생 → try 블록의 `print("A")` 실행 안 됨
- catch에서 `print("B")` 실행
- finally에서 `print("C")` 실행
- 출력: **BC** → **② 정답**. finally는 예외 발생 여부와 무관하게 항상 실행.

### 문제 65
```
range(1,5) = 1,2,3,4
x % 2 == 0 → x = 2, 4
x*2 → 4, 8
```
결과: **[4, 8]** → **② 정답**.

### 문제 69 (LRU 손추적 — 프레임 3, 참조열 12개)
```
참조: 1 2 3 4 1 2 5 1 2 3 4 5
1: [1]           F(1)
2: [1,2]         F(2)
3: [1,2,3]       F(3)
4: [2,3,4]       F(4)  ← 1 최오래(LRU)
1: [3,4,1]       F(5)  ← 2 최오래
2: [4,1,2]       F(6)  ← 3 최오래
5: [1,2,5]       F(7)  ← 4 최오래
1: [1,2,5] hit         (1 재접근)
2: [1,2,5] hit         (2 재접근)
3: [2,5,3]       F(8)  ← 1 최오래
4: [5,3,4]       F(9)  ← 2 최오래
5: [5,3,4] hit         (5 재접근)
```
총 페이지 폴트: **10** → **③ 정답**.

### 문제 70 (Optimal 손추적 — 프레임 3, 같은 참조열)
```
참조: 1 2 3 4 1 2 5 1 2 3 4 5   (미래 참조 기반)
1: [1]           F(1)
2: [1,2]         F(2)
3: [1,2,3]       F(3)
4: [1,2,4]       F(4)  ← 3은 미래에서 가장 나중(pos 10)이지만 4가 새로 옴. Optimal은 "가장 나중에 참조될 페이지 교체". {1: next=5, 2: next=6, 3: next=10}. 3이 가장 나중 → 3 교체 → [1,2,4]
1: [1,2,4] hit
2: [1,2,4] hit
5: [1,2,5]       F(5)  ← {1: next=8, 2: next=9, 4: never}. 4가 가장 나중(∞) → 4 교체
1: [1,2,5] hit
2: [1,2,5] hit
3: [3,2,5]       F(6)  ← {1: never, 2: never, 5: 12}. 1이 가장 나중(∞, 동률) → 1 교체
4: [3,4,5]       F(7)  ← {3: never, 2: never, 5: 12}. 2 교체
5: [3,4,5] hit
```
총 페이지 폴트: **7** → **② 정답**.

### 문제 71
**FCFS는 비선점**(도착 순서대로 완료까지 CPU 점유). **④ 정답**. RR·SRT·MLFQ는 모두 선점형.

### 문제 72
교착상태 4대 필요조건: **상호 배제, 점유 대기, 비선점, 순환 대기**. **④ 선점은 오히려 데드락 해소 조건**. 정답 ④.

### 문제 78
`255.255.255.192` = `11111111.11111111.11111111.11000000` → 네트워크 비트 26, **호스트 비트 = 32-26 = 6**. **② 정답**. 사용 가능 호스트 = 2^6 - 2 = 62.

### 문제 81
CMMI 5단계: Initial(1) → Managed(2) → Defined(3) → Quantitatively Managed(4) → **Optimizing(5, 최고)**. **④ 정답**.

### 문제 82
CMMI 3단계 **Defined**: 조직 표준 프로세스 문서화, 전사 적용, 프로젝트별 tailoring. **③ 정답**. 2단계(Managed)는 프로젝트별 관리, 4단계(Quantitatively Managed)는 정량 관리.

### 문제 87
5G 3대 특성: **eMBB(초광대역), URLLC(초저지연·초신뢰), mMTC(초연결)**. **④ 초경량은 5G 특성 아님**. 정답 ④.

### 문제 88
**RSA는 비대칭키(공개키) 알고리즘**. **④ 정답**. AES/DES/SEED/ARIA/HIGHT는 모두 대칭키.

### 문제 89
**RSA 안전성**: **소인수분해 문제**의 계산적 어려움. **② 정답**. 큰 두 소수 곱 N을 인수분해하는 것이 어려움 근거.

### 문제 90
해시 함수는 **일방향(비가역)**. **④ 가역 복호화 가능은 오답**. 정답 ④. 특성: 일방향성, 충돌 저항성(약/강), 임의 길이 → 고정 길이, 눈사태 효과.

### 문제 94
**패킷 스니핑은 도청(수동적 공격)**, DDoS(가용성 침해)와 성격이 다름. **④ 정답**. DDoS: SYN/UDP/ICMP Flooding, Slowloris, Amplification.

### 문제 95
**오용(Signature/Misuse) 탐지**: 사전 정의 시그니처와 매칭. **② 정답**. 이상(Anomaly) 탐지는 정상 프로파일 이탈 감지.

### 문제 99
**Authorization Code Grant**: 웹 서버 애플리케이션에서 가장 많이 사용, 안전. **② 정답**. Password/Implicit는 보안 이슈로 권장 안 됨(OAuth 2.1에서 제거).
